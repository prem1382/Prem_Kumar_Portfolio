# Prem Kumar M - FullStack Developer Portfolio

## Overview
This is a single-page developer portfolio website built for Prem Kumar M (Computer Science Engineer).
It features a Cyberpunk / Neon dark-mode UI design, interactive scroll progress bar, animated directional arrows, Base64 embedded portrait, and high-impact HR resume sections.

## Files Included
- index.html: Main portfolio website (standalone HTML, CSS, JavaScript).
- portfolio_landing_page.html: Duplicate entry point for easy deployment.
- profile_photo_cyberpunk.jpg: High-resolution portrait with Cyberpunk dark background.
- profile_photo.jpeg: Original extracted portrait image.

## How to Run / View
1. Double click on index.html or open it with any web browser (Chrome, Edge, Firefox, Safari).
2. To host online, simply upload index.html to Netlify, Vercel, GitHub Pages, or any web host.
